Пакет для работы с результатами спортивного "Что? Где? Когда?"

Цель
Помоь исследователям понимать процессы на основе данных. 

Компоненты 
- набор команд, который позволяет по API получать актулаьную информацию
- данные для дальнейшего использования в приложениях и исследованиях

Суть
Регулярно собираем данные по API, приводим их в соответствующий вид, складываем в видел SQL-таблиц, регулярно обновляем данные по свежим турнирам. 

Приложения и исследователи делают SQL-запросы с нужными ими выборками, соновной массив хранится и обновляется централизованно. 

Реализация
Код проверяем локлаьно на компьютере пользователя. 
Прод разоврачиываем на виртуальной машине, настариваем там планировщик. 

Целевая картина
Нужные таблицы обновляются по расписанию. Параметры раписания храним в конфиге, который пользователь может менять. 
Пользователю доступны следующие дополнительные команды:
- тестовая загрузка небольшого набора данных (например, одного турнира)
- обычное обновление вне расписания (на случай поломок)
- перезапись всех данных от начала времён (долгий процесс, с визуализацией статусов и возможности продолжения после экстренной остановки)

Важно
Критично сделать так, чтобы данные не дулировались. 
Нужен жёсткий pipeline, сначала новые данные приходят во временную таблицу, проверяются на валидность, только после этого старые стираются, а новые записываются на их место
